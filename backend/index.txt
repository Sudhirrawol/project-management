Redis is designed around fast operations on data structures that are primarily kept in memory (RAM).

redis->ram->very fast access
This is one reason Redis is commonly used for things that need quick access.

Redis
 ├── Caching
 ├── Sessions
 ├── Rate limiting
 ├── Counters
 ├── Pub/Sub
 ├── Leaderboards
 ├── Distributed locks
 └── temporary application data

 Redis is an in-memory data store.

 What is memory?

Your computer/server mainly has:

RAM       → very fast, temporary working memory
Disk/SSD  → persistent storage

RAM:  16 GB
SSD:  500 GB

Accessing data already available in RAM is generally much faster than accessing persistent storage.

SET

5. What if the key doesn't exist?

Suppose we never stored:

age

and ask:

GET age

Redis has nothing for that key, so the Redis CLI returns a missing value (commonly shown as nil).
